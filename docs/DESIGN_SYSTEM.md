# Designsystem — Kinetic Studio
## Gestaltungsprinzip
Konsole-inspiriertes Bewegungsgefühl, aber eigenständige Identität. Realistische Avatare, Architektur und Licht; reduzierte Touch-Oberflächen. Keine Glow-Überladung, keine standardisierten KI-Dashboard-Kachelwände.

## Vorläufige Tokens (zu validieren)
- background #101A1D; surface #1C2B30; surfaceRaised #26383D
- text #F4F2EC; muted #A9B8BB
- primary #FF704B (Korallorange); motion #47D4D0 (Türkis)
- success #41B883; warning #F2BC60; error #E16C69
- Radius 12/18/24px; spacing 4/8/12/16/24/32px; Inter oder ähnliche gut lesbare Schrift, keine ungeprüften Fontlizenzen.

## Eigene Signaturen
1. Motion-Spur: kurzlebige, dezente Nachbilder vergangener Körperposen.
2. Präzisionsring: bodennahe Visualisierung der geschätzten Übungsübereinstimmung.
3. Dynamische Raumbeleuchtung: zurückhaltende Reaktion auf Trainingsphasen.

## Mobile Navigation
Start, Training, Scan/Live, Fortschritt, Profil. Bildschirmübersicht: Start, Bibliothek, Trainingsplan, Kalibrierung, Darstellungswahl, Live-Training, Ergebnis, Fortschritt, Challenges, Einstellungen. TV: Trainer und Spieler zentral, reduzierte HUD-Daten.

## UI-Zustände
Initial, Laden, Kamerazugriff verweigert, keine Person, Teilkörper/geringe Konfidenz, kalibriert, bereit, läuft, pausiert, abgeschlossen, Verbindung getrennt, Wiederverbindung, Fehler. Jeder Zustand braucht eindeutiges Feedback und erreichbare Aktionen.

## Responsive
Smartphone Portrait als Steuergerät, TV 16:9 mit großzügigen Safe-Areas und lesbaren Texten aus 3m Entfernung. Keine erzwungene 1:1-Übernahme der Mobilnavigation auf TV.
